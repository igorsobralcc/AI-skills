# React baseline

- Organize components, hooks, schemas, tests, and styles by feature; keep reusable primitives in a controlled design-system area.
- Use strict TypeScript and type-aware linting. Validate external data at runtime.
- Use one primary exported component, hook, context, or store per file. Put independently reusable types in their own matching files.
- Derive state instead of synchronizing duplicates. Use effects only to synchronize with external systems.
- Enforce hooks and accessibility linting, formatting, type checking, component or integration tests, feature coverage, and a production build.
