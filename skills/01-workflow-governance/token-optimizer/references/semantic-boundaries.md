# Semantic boundaries

Review meaning before length: task fulfillment, fidelity, exact content, format/language, then style. A shorter answer that changes required meaning fails.

| Sensitive distinction | Preserve |
| --- | --- |
| Negation and scope | “Only retry 503; never retry 401” is not “retry errors” |
| Boundaries | Greater than zero and at most ten means `0 < x <= 10` |
| Quantity and precision | At least 250 ms is different from exactly 250 ms; retain negative signs and zero |
| Choice and actors | A or B but not both; operator may stage, owner may publish |
| Ordering | Back up, verify the backup, then delete the named resource |
| Evidence | Suspected cause is not confirmed; failing checks are not successful verification |
| Attribution | Conflicting source claims remain attributed and unresolved |
| Execution | A planned edit, an applied edit, and a tested edit are separate facts |

Exact literals are task evidence. Preserve supplied capitalization, punctuation, quoting, flags, whitespace when significant, and encoding-sensitive text. An excerpt must be identified as an excerpt and retain the decisive information. Never silently repair a command under an explanation-only request. Conversely, an explicit correction task permits the requested change; describe the changed behavior accurately. Do not abbreviate complete SQL, patches, or structured data with prose.

Language follows the user, including progress and clarification. Preserve foreign technical terms and exact error messages within that language. Do not use classical-language substitutions, automatic translation, or remove case markers, particles, and postpositions carrying relationships.

An inline email draft is an artifact even if never saved. Formal drafts stay complete and professional under ultra. A terse commit message can be terse when specifically requested. Respect structured output requirements exactly; extra activation acknowledgments can invalidate JSON-only answers.

Clarity applies locally. Name the account being deleted and the actor performing deletion if pronouns could confuse them. Explain prerequisites and order in full when needed. Expand a confusing passage rather than replacing it with another ambiguous fragment. This does not reset the session preference.

For findings, retain evidence, consequence, and useful action when relevant. For errors, retain the decisive excerpt and blockers affecting confidence. For progress, keep meaningful host-required updates. For final answers, report the actual outcome and verification rather than implying success from an attempt.
